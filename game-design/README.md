# Game Design + Simulation

Promise: turn game rules into simulations, balance evidence, and playable artifacts.

Storyweaver owns the generic schema, simulation, and export path. Tucked in Terrors is the first
demanding reference pack. Authored D&D and other game worlds remain creative works, not compulsory
engine plugins. March Madness stays independent unless a specific shared experiment/report contract
reduces complexity without blurring its sports-data product.

First move: express one Tucked in Terrors simulation as a versioned pack and prove statistical and
artifact parity against its current simulator.

Verified: none (0/5). All 5 waves carry source-backed prototype receipts; a prototype
proves only what its runner read, never recovered functionality.

Next wave: G1 — fingerprint Tucked in Terrors rules, seeds, metrics, and report outputs into a
parity fixture capturing version, configuration, runs, statistics, and tolerances.
