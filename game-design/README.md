# Game Design + Simulation

Promise: turn game rules into simulations, balance evidence, and playable artifacts.

Storyweaver owns the generic schema, simulation, and export path. Tucked in Terrors is the first
demanding reference pack. Authored D&D and other game worlds remain creative works, not compulsory
engine plugins. March Madness stays independent unless a specific shared experiment/report contract
reduces complexity without blurring its sports-data product.

Wave progress snapshot (2026-10-15): (5/5) verified. G1's source-execution receipt is recorded; the
next runtime step is to express one simulation as a versioned pack and measure independent
statistical and artifact parity. A donor run by itself does not prove parity or human playability.

Current evidence: G1 executes 1,000 donor simulations and host-checks the result and provenance;
G2 projects the donor into the Storyweaver pack shape without measuring parity; G3–G5 retain their
declared boundary and schema analyses. Human playtesting remains open.
