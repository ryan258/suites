# Brand + Publishing OS

Promise: turn governed brand truth and sourced ideas into approved, traceable publications.

Brand System Maker owns the versioned brand source of truth. Brand Workshop contributes its
sequential low-typing intake. Cyborg and VCC own drafting/refinement; Talk-to-Blog and Cyborg Agent
own source adapters; Blog Factory and Clout Machine own controlled execution and learning. Case
study sites remain fixtures, never proof of real commerce or publication.

Verified: B1, B2 (2/6). B1 exported a versioned `BrandPackage` from live `brand-maker-spec`
sources and validated it in a `cyborg` dry-run consumer under version pinning and mutation
protection, with no publishing side effects. B2 mapped Brand Workshop's nine low-typing phases onto
Brand Maker workspace state and gates. Both are analysis milestones; exporting from the real Brand
Maker runtime and implementing the mapped gates remain outstanding.

Next wave: B3 — model sourced draft → VCC review → dry-run publishing receipt through the
suite-local engine, with nothing submitted to VCC.
