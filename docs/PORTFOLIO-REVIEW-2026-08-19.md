# Comprehensive Portfolio Review — 2026-08-19

## Executive decision

The portfolio is now governed as eight suites, fourteen independent/archive/container items, and a
set of nested sources that are explicitly distinguished from products. The durable thesis remains:

> Local-first, evidence-bound, accessible systems that help a high-cognitive, variable-bandwidth
> operator turn difficult work into reviewable artifacts.

Projects survive when they own durable state, provenance, deterministic verification, specialized
low-friction interaction, real-world execution, a repeatable production pipeline, or a unique
corpus. Generic persona rosters, prompt chains, one-shot generators, and extra orchestration
surfaces do not survive as standalone products merely because code exists.

## Portfolio shape

### Active bets

1. **Accessibility** is the flagship because it already combines real scanning, evidence contracts,
   teaching, practitioner guidance, browser assistance, human gates, and lifecycle reporting.
2. **Operator OS** protects the operator's actual daily context. Dotfiles owns capture/control,
   PKOS owns source truth, Observer owns derived projection, and JARVIS owns presentation.
3. **Brand + Publishing** turns governed brand state and sourced ideas into reviewed artifacts. Its
   moat is provenance, approval, versioning, compliance, and learning—not prose generation.

### Next systems

4. **Production House** is justified only by a Groundwire episode that becomes easier and remains
   auditable through the generic engine.
5. **Model Behavior Lab** consolidates repeated clients, run stores, IDs, and reports around one
   reproducible experiment contract and a versioned benchmark corpus.
6. **Discovery + Decision** keeps Forge as the durable investigation workspace and absorbs only the
   SIF/Insight behavior that preserves typed evidence, consent, budgets, and recovery.

### Labs, not flagship platforms

7. **Agent Reliability** is internal test and teaching infrastructure. It must not become another
   persona marketplace, prompt runner, or all-purpose agent dashboard.
8. **Game Design + Simulation** must prove generality with Tucked in Terrors before asking authored
   games to become engine packs.

## Important non-suite dispositions

- Keep `Tally`, `march-madness`, `alias-scanner`, `bash-rename-toolkit`, and `glowforge-it` as focused
  independent products/utilities while they remain useful.
- Keep `nonsense` as a container; govern its nested creative projects individually.
- Keep `AI_Tic_Tac_Toe_V2` externally owned. Adapter use is not ownership transfer.
- Quarantine `the merge`; its AI Staff and prompt-lab checkouts are divergent evidence, not trash.

  owner instead of growing root catch-alls.
- Empty folders remain visible in the ledger until a separate, explicit cleanup decision. Nothing
  was deleted in this reconstruction.

## Cross-system policy finding

The current read-only Cyborg audit still reports a high-severity commit-boundary policy drift from
broad commit-capable allow rules in multiple project-local settings. That is a permission-policy
issue requiring human approval; this suite work did not normalize or edit it. No staging, commit,
push, pull request, deployment, publication, or destructive cleanup was performed.

## What this review does not prove

It is not market validation, release certification, deployment evidence, accessibility conformance,
security certification, or proof that every source's current full test suite is green. The suite
rankings are implementation/mission/leverage judgments. Each migration wave must re-check the exact
source fingerprint, working tree, runtime, tests, generated artifacts, and manual gates it relies on.
